The key points for ongoing iOS development:

## Critical rules

1. **Never mint, never write DNA, never re-roll from iOS.** All writes via RPCs.
2. **4 tiers only:** Seed (0–4), Bloom (5–14), Legacy (15–29), Radiance (30+).
3. **`is_owner`, `is_creator`, `is_from_me`, `is_to_me` are `Bool?`** — null when
   called without a user JWT. Never force-unwrap these.
4. **`traits` column** — always an empty object. Never read it.
5. **`dna_version`** — informational only. Never branch rendering on it.
6. **Layer 1 wins, Layer 2 is fallback.** Read `gemFamily` first, fall back to
   `identity.base_form`. Both must agree when both are present.
7. **Do not add a trait overlay on top of the PNG.** Trait is metadata for text/haptics.
8. **`complete_favor_and_mint` does not exist.** Favors only transfer coins.
9. **`my_originals` RPC omits `dna`.** Use `coin_journey` or direct `coins` SELECT.
10. **History is ascending by `created_at`** — newest entry is last, not first.

## Rendering formula

```
gem_<gemFamily>_<tier>.png   +   frame_<gemFamily>_<tier>.png
```

`gemFamily` ∈ `lightning | celestial | victorian | gothic`
`tier` derived from `transfer_count` via `Tier.from(transferCount:)`

## DNA fallback chain

```swift
let family = dna?.resolvedFamily  // gemFamily → identity.base_form → "lightning"
let hue    = dna?.resolvedHue     // primaryHue → identity.primary_color → 45
let sat    = dna?.resolvedSaturation // saturation → identity.saturation → 0.7
```
